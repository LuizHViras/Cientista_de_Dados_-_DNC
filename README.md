# Curso - Cientista de Dados - DNC

Este repositório tem como objetivo **centralizar minhas atividades práticas, anotações e resumos** desenvolvidos ao longo de um curso de **Cientista em Dados**.  
O foco é consolidar conhecimento técnico, estruturar conceitos e criar material de referência para uso profissional.

Aqui você encontrará:

* Resumos teóricos das aulas

* Exercícios práticos

* Anotações técnicas

* Projetos aplicados conforme disponibilidade no curso

O conteúdo será atualizado de forma progressiva, acompanhando a evolução das disciplinas.
