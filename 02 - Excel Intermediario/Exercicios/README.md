Excel Intermediário – Guia Completo de Aprendizado
==================================================

📊 Visão Geral
--------------

Este repositório contém os exercícios, práticas e desafios desenvolvidos durante o módulo **Excel Intermediário** do curso da **Dinâmica**.

O objetivo do módulo é aprofundar o domínio do Excel para **análise de dados, manipulação de informações, automação de cálculos e criação de visualizações profissionais**.

Durante o curso foram abordados:

* Manipulação avançada de planilhas

* Funções matemáticas, lógicas e de busca

* Limpeza e estruturação de dados

* Ferramentas de análise

* Visualização de dados

* Tabelas dinâmicas

* Criação de dashboards

Ao final do módulo, o aluno é capaz de construir **planilhas robustas voltadas para análise de dados e suporte à tomada de decisão**.

* * *

🧭 Estrutura do Módulo
======================

Os exercícios seguem o padrão **IP - EX (Intermediário Prática - Exercício)**.

No total foram realizados **39 exercícios práticos**, além de **3 Super Exercícios aplicados**.

4️⃣ Funções Lógicas
===================

IP - EX 09 — Função SE
----------------------

A função `SE` permite criar **condições lógicas**.

Exemplo:

=SE(A1>=7;"Aprovado";"Reprovado")

Aplicações:

* classificação de dados

* validações

* sistemas de decisão

* * *

IP - EX 10 — Função SE Avançada
-------------------------------

Uso de **múltiplos SE aninhados** para criar classificações mais complexas.

Exemplo:

=SE(A1>=9;"Excelente";SE(A1>=7;"Bom";"Ruim"))

* * *

IP - EX 14 — Funções Lógicas (E / OU)
-------------------------------------

Combinação de múltiplas condições:

=E(condição1; condição2)  
=OU(condição1; condição2)

Permite análises como:

* aprovação baseada em múltiplos critérios

* validação de regras de negócio

1️⃣1️⃣ Funções de Busca
=======================

IP - EX 28 — ÍNDICE + CORRESP
-----------------------------

Sistema de busca avançado.

Permite:

* busca bidimensional

* maior flexibilidade que PROCV

* * *

IP - EX 29 — PROCV
------------------

Busca vertical em tabelas.

Exemplo:

=PROCV(A2;Tabela;2;FALSO)

Muito utilizado para:

* cruzamento de bases

* consultas de dados

* * *

IP - EX 30 — PROCH
------------------

Versão horizontal do PROCV.

Busca informações em linhas.

* * *

IP - EX 31 — PROCX
------------------

Função moderna de busca no Excel.

Vantagens:

* substitui PROCV e PROCH

* permite busca reversa

* separa matriz de busca e retorno

* tratamento de erros integrado

* * *
