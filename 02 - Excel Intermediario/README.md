📊 Módulo 02 - Excel Intermediário
===============================

Este módulo tem como objetivo desenvolver domínio intermediário do Excel aplicado à análise de dados, focando em produtividade, organização de informações e criação de análises visuais.

O conteúdo aborda desde a ambientação na ferramenta até recursos mais analíticos, como fórmulas, gráficos e tabelas dinâmicas, preparando a base para módulos avançados e automação futura.

* * *

## 📌 Status do Módulo

**Concluído ✅**

---

🎯 Objetivos do Módulo
----------------------

Ao final deste módulo, o foco é ser capaz de:

* Navegar e utilizar o Excel com eficiência

* Construir planilhas organizadas e profissionais

* Aplicar funções para cálculos e análises

* Utilizar formatações para melhorar leitura e interpretação

* Analisar dados com filtros e segmentações

* Criar gráficos claros para comunicação de informações

* Utilizar tabelas dinâmicas para resumir grandes volumes de dados

* * *

🧭 Conteúdos Principais
-----------------------

### 🖥️ Ambientação no Excel

Familiarização com a interface e principais áreas de trabalho:

* Barra de ferramentas

* Faixa de opções

* Planilhas e células

* Barra de fórmulas

* Modos de exibição

* Operações básicas (abrir, salvar, imprimir)

Objetivo: aumentar velocidade e eficiência no uso diário.

* * *

### ➗ Funções

As funções representam o núcleo do Excel para análise de dados.

Principais grupos abordados:

* Funções matemáticas e estatísticas
  
  * SOMA, MÉDIA, MÁXIMO, MÍNIMO

* Funções lógicas
  
  * SE

* Funções condicionais
  
  * CONT.SE, SOMASE

* Funções de busca e referência
  
  * PROCV

* Funções de arredondamento
  
  * ARRED, TETO

* * *

### 🎨 Formatação

Melhoria da legibilidade e organização visual das planilhas:

* Formatação de textos e células

* Bordas e preenchimentos

* Cores e estilos

* Formatação condicional

* Validação de dados

Uma boa formatação facilita interpretação e reduz erros.

* * *

### 📈 Análise de Dados

Ferramentas para organizar e resumir informações:

* Classificação e filtros

* Subtotais

* Consolidação de dados

Esses recursos permitem transformar dados brutos em informações úteis.

* * *

### 📊 Gráficos

Criação de visualizações para identificação de padrões e tendências:

* Colunas e barras

* Linhas e áreas

* Pizza e rosca

* Dispersão e bolhas

A escolha correta do gráfico é parte essencial da análise.

* * *

### 🧩 Tabelas Dinâmicas

Uma das ferramentas mais importantes do Excel para análise:

* Resumo automático de dados

* Agrupamentos dinâmicos

* Cálculos e estatísticas

* Atualização automática

* Criação de relatórios flexíveis
